帳號分組批次移動

把帳號貼進對應的目錄，產生一份可以直接跑的腳本，整批調整 bluecg.net 的帳號分組與排序

這在解決什麼

帳號多的時候，要把幾十個帳號搬到「倉庫」或「棄置」，得一個一個點開選單再選分組，整組搬完手會廢掉。

原理是：移動一個帳號＝開一個網址，所以把網址列出來交給腳本連續開完就好。

https://www.bluecg.net/plugin.php?id=gift:array&ID=<帳號>&zu=<目錄代號>
0置頂
1戰鬥
2生產
3倉庫
4販賣
5普通
6棄置
前提：動手前先在 Chrome 打帳號密碼登入 bluecg.net，並勾「記住登入」。沒登入的話，腳本開過去的每個網址都只會是登入頁，整批白跑而且看不出來。

全程走你自己登入的 Chrome，這頁只負責產生文字，不會連到 bluecg.net，也收不到你的帳號資料。需要的東西：Windows、Chrome，不用裝額外軟體。

1抓出現有的帳號清單

不用一個一個打字。在已登入的帳號管理頁按 F12 開開發者工具，切到 Console 分頁，貼上這行按 Enter，目前的分組與帳號就進剪貼簿了：

copy([...document.querySelectorAll('ul[id^="category_"]')].map(ul=>{const zu=ul.id.slice(9);const a=[...ul.querySelectorAll('a.zhanghao-link')].map(x=>new URL(x.href).searchParams.get('ID'));const g=ul.querySelector('a[id$="帳號"]');return a.length?`# 分組 ${zu} ${g?g.id.split('_').pop():''}（${a.length}）\n`+a.join('\n'):''}).filter(Boolean).join('\n\n'))
  • 第一次貼會被 Chrome 擋住，畫面會要你先手動打 allow pasting 按 Enter，打完就能貼了。
  • 執行後只回一行 undefined 是正常的，copy() 本來就不回傳值，清單已經在剪貼簿裡。
  • 只印出一組的話，就是網頁只把展開的那組放進畫面，切到其他分組再各跑一次。

這步只是方便你知道自己有哪些帳號。已經有清單的話可以直接跳到步驟 2。

2貼進要搬去的目錄

一格一個目錄，貼上你想搬到那一格的帳號，一行一個。# 開頭的行會自動跳過，所以上一步複製的標題行留著沒關係。不用動的目錄留空就好。

3執行

兩個檔案放在同一個資料夾，然後點 move-accounts.bat。ps1 不能雙擊執行，bat 只是幫忙用對的參數叫起 PowerShell：

@echo off
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0move-accounts.ps1"
pause
每次執行都會停下來一次。腳本會用一個獨立設定檔另外開 Chrome（不會動到你平常那個），在裡面打開 bluecg.net 然後等你確認是登入狀態。要手動打 yes 才會開始搬，直接按 Enter 會中止——這是故意的，免得順手按過去。沒登入的話整批都會白跑，畫面上每一筆還是會印成功，所以這一下請真的看一眼。
下載 .bat、.ps1 時 Chrome 會問「這類檔案可能有害，要保留嗎」，這是它對這兩種副檔名的固定警告。建議用下載而不是自己複製貼上存檔，下載的檔已經寫好 UTF-8 BOM；沒有 BOM 的話 PowerShell 5.1 會把中文訊息讀成亂碼。
跳出「無法開啟這些檔案／網際網路安全性設定」的話，是 Windows 對網路下載檔案的封鎖（Mark of the Web），不是防毒。右鍵那個檔 → 內容 → 最下面勾解除封鎖 → 確定。從 zip 解壓的要先對 zip 本身解除封鎖再解壓，或整個資料夾跑一次 Get-ChildItem | Unblock-File。

手動版：用 accounts.txt

不想把帳號貼在網頁上、或想把清單存成檔案自己管理的話，用這個版本。一次只處理一組，帳號放在旁邊的 accounts.txt，腳本去讀它。

展開手動版的檔案與說明

下載 move-accounts.zip

zip 裡是 move-accounts.ps1、move-accounts.bat 和一個空的 accounts.txt。也可以照下面的原始碼自己存檔，記得存 UTF-8。

accounts.txt 長這樣，一行一個帳號，# 開頭的行會自動跳過，所以步驟 1 複製的標題行留著沒關係：

# 分組 5 普通帳號（100）
Account01
Account02
Account03

# 分組 3 倉庫帳號（42）
Storage01
Storage02

只留下這次要移動的帳號，其他整行刪掉，因為這版不分組，整個檔案會一起搬到同一個 $Zu。

move-accounts.ps1，要改的只有最上面的 $Zu：

# BlueCG 帳號批次移動：開一個分頁、等網頁跑完、關掉，再換下一個

$Zu          = 3                                                           # 0置頂 1戰鬥 2生產 3倉庫 4販賣 5普通 6棄置
$AccountFile = "$PSScriptRoot\accounts.txt"
$WaitSec     = 1.5                                                         # 每個分頁停留秒數
$Port        = 9222
$UserDir     = "$env:LOCALAPPDATA\bluecg-chrome"
$ChromeExe   = "$env:LOCALAPPDATA\Google\Chrome\Application\chrome.exe"

# ---------------- 檢查 ----------------
if ($Zu -lt 0 -or $Zu -gt 6) { Write-Host "Zu 只能填 0-6，目前是 $Zu"; exit 1 }
if (-not (Test-Path -LiteralPath $AccountFile)) { Write-Host "找不到帳號檔：$AccountFile"; exit 1 }
if (-not (Test-Path -LiteralPath $ChromeExe))   { Write-Host "找不到 Chrome：$ChromeExe"; exit 1 }

$accounts = @(Get-Content -LiteralPath $AccountFile -Encoding UTF8 |
              ForEach-Object { $_.Trim() } |
              Where-Object { $_ -and -not $_.StartsWith('#') })
if ($accounts.Count -eq 0) { Write-Host "帳號檔是空的"; exit 1 }

# ---------------- 啟動遙控用的 Chrome ----------------
$base  = "http://127.0.0.1:$Port"
$alive = $false
try { Invoke-RestMethod "$base/json/version" -TimeoutSec 2 | Out-Null; $alive = $true } catch {}

if (-not $alive) {
  Write-Host "啟動 Chrome（遙控設定檔：$UserDir）"
  Start-Process -FilePath $ChromeExe -ArgumentList @(
    "--remote-debugging-port=$Port",
    "--user-data-dir=$UserDir",
    '--no-first-run',
    '--no-default-browser-check',
    'about:blank')
  for ($i = 0; $i -lt 40 -and -not $alive; $i++) {
    Start-Sleep -Milliseconds 500
    try { Invoke-RestMethod "$base/json/version" -TimeoutSec 2 | Out-Null; $alive = $true } catch {}
  }
}
if (-not $alive) { Write-Host "Chrome 遙控介面沒起來（$base）"; exit 1 }

# 每次都問。設定檔資料夾還在但 cookie 過期時，整批會開成登入頁而且看起來像成功
Invoke-RestMethod -Method Put -Uri "$base/json/new?$([uri]::EscapeDataString('https://www.bluecg.net/'))" | Out-Null
$ans = (Read-Host "剛開的分頁是 bluecg.net，確認畫面是已登入狀態了嗎？打 yes 繼續，其他任何輸入都中止").Trim()
if ($ans -ne 'yes' -and $ans -ne 'y') { Write-Host "已中止，沒有動到任何帳號"; exit 1 }

# ---------------- 逐一移動 ----------------
Write-Host ""
Write-Host "移動到目錄 zu=$Zu，共 $($accounts.Count) 個帳號"
$failed = @()
$n = 0
foreach ($acc in $accounts) {
  $n++
  $url = "https://www.bluecg.net/plugin.php?id=gift:array&ID=$acc&zu=$Zu"
  try {
    $tab = Invoke-RestMethod -Method Put -Uri "$base/json/new?$([uri]::EscapeDataString($url))"
    Start-Sleep -Milliseconds ([int]($WaitSec * 1000))
    Invoke-RestMethod "$base/json/close/$($tab.id)" | Out-Null
    Write-Host ("[{0}/{1}] {2}" -f $n, $accounts.Count, $acc)
  } catch {
    $failed += $acc
    Write-Host ("[{0}/{1}] {2}  失敗：{3}" -f $n, $accounts.Count, $acc, $_.Exception.Message)
  }
}

Write-Host ""
Write-Host "完成 $($accounts.Count - $failed.Count)/$($accounts.Count)"
if ($failed.Count -gt 0) { Write-Host ("失敗：" + ($failed -join ', ')) }

bat 跟上面步驟 3 那個一模一樣，兩版共用。

想調同一組裡的順序

同一個目錄裡的排列順序＝送出的順序，先送的排前面，也就是你在格子裡貼的行順序。要在原目錄內重排，不能原地重送，得先整批搬去別組中轉，再照想要的順序搬回來：

  1. 把那批帳號貼到一個暫時的目錄（例如 0 置頂），產出、執行
  2. 回到這頁，把同一批帳號改成你要的行順序，貼回原本那一格
  3. 再產出、執行一次

兩輪之間等第一輪跑完再做就好，腳本每個帳號之間有 $WaitSec 的間隔。

驗證狀態

哪些真的試過、哪些沒有，先講清楚：

  • 已驗證步驟 1 的 Console 那行，拿實際存下來的帳號管理頁 HTML 跑過，100 個帳號全部抓出。
  • 未驗證帳號管理頁是不是七組都同時在頁面資料裡，目前只確認過其中一組。
  • 未驗證zu 代號與目錄的對應來自論壇分享文，沒有七組逐一實測。第一次用先只填一格、放一個不重要的帳號，確認搬對地方再整批跑。
  • 未驗證產出的腳本沒有實際跑過完整一輪。
移動會真的改掉帳號的分組狀態，而且沒有還原按鈕。按下去之前先看一眼產出的腳本裡是不是只有你要動的帳號。
